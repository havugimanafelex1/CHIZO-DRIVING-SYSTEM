# HAVUGIMANA CHIZO FELEX DEV Driving System

A React + Vite frontend prototype based on the two handwritten HAVUGIMANA CHIZO FELEX DEV Driving System sketches.

## Included
- Responsive home page with hero image and driving school introduction
- About, Programs, Theory and Contact pages
- English / Kinyarwanda language switch
- Registration form with local demo state
- Admin dashboard preview with sample learner registrations
- Footer with social links

## Requirements
- Node.js (LTS recommended)
- VS Code (recommended)

## Run on Windows (PowerShell)
1. Extract this ZIP.
2. Open the extracted `chizo-driving-system` folder in VS Code.
3. Open Terminal and run:

```powershell
npm install
npm run dev
```

4. Open the local URL printed by Vite, usually `http://localhost:5173`.

## Important
This is the frontend prototype. Registration data is kept only in browser memory and sample admin data is included. It does not yet have real login, database storage, payment processing, or a backend API. Replace the demo email/phone with the school's real contacts before publishing.

## Build
```powershell
npm run build
```
